## Custom Recipes

NutriMate allows users to create and manage their own custom recipes. Each recipe consists of:
- **Name**: Recipe name (required)
- **Ingredients**: List of ingredients with amounts (required)
- **Calories**: Total calories per serving (required)
- **Photo**: Optional image URL

All recipes are user-created and stored in the database. There are no external recipe imports.
